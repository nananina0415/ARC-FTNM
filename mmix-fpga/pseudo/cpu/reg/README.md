# 레지스터 접근

`Registers`는 범용 레지스터의 읽기 2포트·쓰기 1포트와 특수 레지스터 GET/PUT 버스를
제공한다. rA/rD/rH/rM/rR는 기존 ALU 직접 배선과 GET/PUT에서 같은 저장 상태를 사용한다.
CPU는 GET/PUT 실행 중 ALU 쓰기를 차단해 두 쓰기 경로가 동시에 활성화되지 않게 한다.

`SpecialAccess`는 현재 지원 가능한 특수 레지스터와 쓰기 값을 검사한다. 지원 대상은
번호 0~7 및 21~31인 `rB,rD,rE,rH,rJ,rM,rR,rBB,rA,rF,rP,rW,rX,rY,rZ,rWW,rXX,rYY,rZZ`다.
이 중 trap/호출 관련 저장 셀을 읽고 쓸 수 있다는 것이 trap/호출 실행 지원을 뜻하지는 않는다.

번호 8~20인 시스템·스택 레지스터는 관련 상태 전이와 부작용을 구현하기 전까지
GET/PUT를 거부한다. 특히 rG/rL을 평면 레지스터 파일의 변수처럼 쓰도록 허용하지 않는다.
향후 해당 모듈과 상태 전이를 연결할 때 접근 정책을 확장한다.

rA는 기존 4비트 저장 구조를 유지한다. MMIX 비트 6/7은 V/D 이벤트, 14/15는 각 enable이며
GET은 나머지 비트를 0으로 읽는다. PUT 값에 마스크 `0xc0c0` 밖의 비트가 있으면 거부한다.
거부는 CPU의 decoded_valid에 반영해 실행 전에 무효 명령 fault로 처리한다.

현재 접근 경로와 생성 RTL은 구현했으며 테스트·시뮬레이션은 실행하지 않았다.
