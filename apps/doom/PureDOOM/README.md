# PureDOOM for Global Poor Porters

본 저장소는 PureDOOM의 포크입니다.

PureDOOM의 다국어 지원 기반을 마련하고, 기능이 부족한 CPU, MPU에서 동작할 수 있도록 합니다.

원본 PureDOOM에 관한건 아래를 참조.

[[원본 저장소](https://github.com/Daivuk/PureDOOM)] [[원본 리드미](./PureDOOM-README.md)]

## 지원 목표

- [x] 부동소수점 사용 코드 제거
- [ ] 유니코드 지원
  - 폰트 해상도 때문에 640x480 해상도 사용
  - 폰트 레이어만 640x480이며, 그 외 그래픽은 320x200에서 업스케일링
  - 우선 4 바이트 배열로 지원하며, 추후 UTF-16으로 전환
  - [ ] UTF-16 문자열 부분 지원. 2바이트짜리만 사용. 서로게이트 문자는 무시됨.
- [ ] 다국어 번역을 위한 기반
  - [ ] 소스코드 내부 상수가 아닌 외부 파일 파싱으로 로드
  - [ ] 여러 번역본 파일 중 하나만 포함하는 빌드
  - [ ] 여러 번역본을 포함하여 게임 내에서 언어 선택 가능한 빌드
