# PureDOOM for Global Poor Porters

본 저장소는 PureDOOM의 포크입니다.

PureDOOM의 다국어 지원 기반을 마련하고, 기능이 부족한 CPU, MPU에서 동작할 수 있도록 합니다.

원본 PureDOOM에 관한건 아래를 참조.

[[원본 저장소](https://github.com/Daivuk/PureDOOM)] [[원본 리드미](./PureDOOM-README.md)]

## 지원 목표

- [x] 부동소수점 사용 코드 제거
- [ ] 유니코드 지원
  - 폰트 해상도 때문에 640x480 해상도 사용
  - 폰트 레이어만 640x480이며, 그 외 그래픽은 320x200에서 업스케일링
  - 우선 4 바이트 배열로 지원하며, 추후 UTF-16으로 전환
  - [ ] UTF-16 문자열 부분 지원. 2바이트짜리만 사용. 서로게이트 문자는 무시됨.
- [ ] 다국어 번역을 위한 기반
  - [ ] 소스코드 내부 상수가 아닌 외부 파일 파싱으로 로드
  - [ ] 여러 번역본 파일 중 하나만 포함하는 빌드
  - [ ] 여러 번역본을 포함하여 게임 내에서 언어 선택 가능한 빌드

## 선택 기능 (컴파일 매크로)

컴파일할 때 매크로를 정의하면 켜지고, 정의하지 않으면 원본과 같게 동작합니다.
설명은 `src/DOOM/doom_config.h`에도 있습니다.

| 매크로 | 동작 |
|---|---|
| `DOOM_AUTOMAP_PAUSE` | 싱글플레이에서 자동 지도가 열려 있는 동안 게임 진행을 멈춥니다. 지도 이동·확대는 계속 동작합니다. |
| `DOOM_AUTOMAP_NO_FOLLOW` | 자동 지도 따라가기 모드를 쓰지 않습니다(`f` 키 무시). 지도는 열 때 플레이어 위치에서 시작하고 직접 이동합니다. |
| `DOOM_WEAPON_CYCLE` | 이전/다음 무기 전환 키를 추가합니다. 설정 이름은 `key_prevweapon`/`key_nextweapon`, 기본 키는 `[`/`]`입니다. |

`DOOM_WEAPON_CYCLE`의 전환 순서는 주먹, 전기톱, 권총, 샷건, 슈퍼샷건, 체인건, 로켓, 플라즈마, BFG이며 끝에서 처음으로 돌아갑니다.
갖고 있지 않은 무기, 한 발 쏠 탄약이 없는 무기(BFG 40, 슈퍼샷건 2, 나머지 1), 숫자키로도 고를 수 없는 무기는 건너뜁니다.
무기 번호는 숫자키와 같은 3비트로 보내므로, DOOM II에서 슈퍼샷건을 가지고 있으면 샷건으로 갈 때 슈퍼샷건으로 바뀝니다(원본 숫자키와 같은 규칙).

예:

```c
#define DOOM_AUTOMAP_NO_FOLLOW
#define DOOM_IMPLEMENTATION
#include "PureDOOM.h"
```
